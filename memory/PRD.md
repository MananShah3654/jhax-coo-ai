# JHAX — Product Requirements

## Original Problem Statement
Build "JHAX — The AI Operating System for Restaurant Owners." A voice-first, zero-dashboard executive control center where restaurant owners run their whole business by asking natural-language / voice questions and getting one decisive answer + one-click action. Reuse JhaPay branding (orange #FF6B35 primary). Tagline: "Ask Your Restaurant Anything." Philosophy: **One Question → One Answer → One Action**.

## User Personas
- **Restaurant Owner / CEO** — primary. Needs decisions, not dashboards. Cares about revenue, customers, branch performance, growth.
- **Branch Manager** — receives prioritised tasks generated by AI from the Manager Mode screen.

## Core Requirements (static)
1. PIN-based owner login (reuses JhaPOS visual language).
2. AI COO Home — hero microphone, "Ask Anything" input, KPI tiles (revenue / orders / AOV / tips / customers), Restaurant Health Score ring (0–100, color-coded), Daily CEO Briefing.
3. AI COO Chat — streaming Claude Sonnet 4.5 replies in strict Decision Card format: STATUS / REASON / OPPORTUNITY / ACTION / EXPECTED IMPACT + inline action buttons.
4. Voice-first — Whisper STT for owner questions, OpenAI TTS read-aloud for replies.
5. MCP-style architecture — LLM never touches DB. Backend pre-computes restaurant_context and injects into prompt.
6. AI Guardrails — declines non-restaurant questions with the exact mandated phrase.
7. Multi-location, Marketing AI (campaign generator), Customer Intelligence, Menu Intelligence, Revenue/Forecast, Manager Mode, Action Center, one-click sharing (mocked).

## Tech Stack
- Backend: FastAPI + Python, emergentintegrations (Claude Sonnet 4.5 + Whisper + OpenAI TTS), deterministic mock data (no DB writes — read-only KPIs).
- Frontend: React 19 + Tailwind + react-router + sonner toasts + lucide-react icons. Fonts: Outfit + Manrope + JetBrains Mono.

## Architecture (MCP-style)
Frontend → AI Gateway (/api/ai/chat SSE) → restaurant_context (analytics.py) → Prompt Builder → Claude → Response Formatter (strict JSON Decision Card) → UI.

## Implemented (2026-01)
- PIN login with full keypad + error state, sleek 4-dot indicator.
- AI COO Home: KPIs, Health Ring (Apple-Watch style), Daily CEO Briefing card with risk areas + recommended action + expected opportunity + Launch/Share buttons. Hero "Ask Anything" bar + suggestion chips + floating mic.
- AI COO Chat: SSE streaming with progressive Decision Card rendering, voice read-aloud per reply, inline action buttons that POST to /api/actions/execute and toast.
- Voice mic: MediaRecorder → /api/ai/transcribe (Whisper) → auto-asks AI.
- Branches: ranked table + Best / Needs Attention callouts.
- Customers: VIP + At-Risk lists, repeat-rate, LTV, recovery opportunity.
- Menu Intelligence: top profitable + underperformers tables with margin %.
- Marketing AI: audience/channel/goal form → Claude-drafted subject/body/cta + Launch Campaign.
- Forecast: 30-day projection with bar chart + confidence.
- Manager Mode: AI-generated branch task list with "Send to All Managers".
- Layout: sidebar nav (desktop) + bottom nav (mobile), top-right logout (mobile), JhaPay-orange brand identity throughout.
- Backend tests: 20/20 pytest passing on all /api/* endpoints (auth, dashboard, AI chat, AI streaming SSE, guardrail decline, campaign gen, action execute, reports, STT, TTS).

## Iteration 2 (2026-01)
- **Concise Decision Card**: AI replies now ≤8 word headline, merged reason+opportunity in one tight paragraph, impact pill, 0-3 action chips. No more verbose 5-section wall.
- **Clarification gate**: ambiguous inputs ("you", "ok", "hi") no longer trigger metric dumps — the AI returns a clarify question + 3 suggestion chips that re-ask on click.
- **Real action wiring**:
  - Launch Campaign → /marketing prefilled (audience/channel/goal flow through sessionStorage + location.state).
  - Share Report → global ShareModal: live PDF preview + WhatsApp (wa.me) + Email (mailto:) + Download PDF.
  - Navigate actions → React Router push to the right screen.
- **Real PDF reports**: `/api/reports/{type}/pdf` for all 6 types (daily/weekly/monthly/branch/investor/marketing) via reportlab, branded JHAX executive layout.
- **DataSource adapter**: new `/app/backend/data_source.py` with `MockDataSource` (default) and `JhaPOSDataSource` (HTTP, plug-in via `DATA_SOURCE=jhapos`, `JHAPOS_API_URL`, `JHAPAY_WALLET_API_URL`, `LOYALTY_API_URL`, `JHAPOS_API_KEY` env vars). Falls back per-resource so partial wiring works. `/api/dashboard` now exposes `data_source` field.
- **Backend tests**: 33/33 pytest pass (12 new tests covering PDF + clarify + concision + adapter).
